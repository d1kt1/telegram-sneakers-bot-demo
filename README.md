# Sneaker Store Bot

Telegram-бот магазина кроссовок на aiogram 3.

## Возможности
- Каталог кроссовок с фото и ценой
- Оформление заказа через номер телефона
- Уведомления администратору о новом заказе

## Запуск
1. `pip install -r requirements.txt`
2. Создай `.env`:
   BOT_TOKEN=твой_токен_от_BotFather
   ADMIN_ID=твой_telegram_id
3. `python main.py`
